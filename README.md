# Overexpression-of-Alpha-synuclein-in-Midbrain-Dopamine-Neurons-Drives-Learning-Deficits-in-Mice

The code weas build in order to analyze all the data used in our paper titled "Overexpression of alpha-synuclein in Midbrain Dopamine Neurons Drives Learning Deficits in Mice", including data processing, statistical analyses, and figure generation.

Here, we worked on a progressive mouse model of Parkinson's disease in order to study cognitive impairment in the early phase of the disease. 

## Repository contents

The repository includes scripts for:

- Behavioral data processing and organization.
- Motor behavior analysis (Open Field, Rotarod, Pole Test).
- Instrumental learning analysis.
- Statistical analyses, including linear mixed-effects models and post hoc test.
- Data visualization and figure generation.

## Requirements

Analyses were performed using:

- R and R Studio (version: 2023.10.1 +239)
- Spyder

Relevant packages and dependencies are specified in the individual scripts.
